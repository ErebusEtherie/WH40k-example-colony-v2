# Long-Form Writing Skill

## Activation
This skill activates when you're working with documents longer than 2000 words or when explicitly invoked with "/longform-writing".

## Core Principles
1. Maintain context across chunks without overwhelming the system
2. Create seamless transitions between sections
3. Preserve narrative or argumentative coherence
4. Track recurring themes, characters, or concepts throughout the document

## Section Management

### Starting a New Section
1. Before writing, review the previous section's final paragraph
2. Create a "continuity anchor" - a brief 2-3 sentence summary of key points to carry forward
3. Identify any unresolved elements from the previous section that need addressing
4. Note any stylistic elements to maintain (tone, voice, perspective)

### Transitioning Between Sections
1. Review the last paragraph of the previous section
2. Create a transitional paragraph that:
   - References the previous section's conclusion
   - Sets up the new section's focus
   - Maintains the established tone and style
3. Check for consistency in:
   - Character names and traits (for fiction)
   - Technical terminology (for non-fiction)
   - Timeline and chronology
   - Point of view or narrative voice

### When Continuity Breaks
1. Pause and identify the specific break in continuity
2. Create a "continuity bridge" using the transition template
3. Review the document outline to realign with the overall structure
4. Add a placeholder note for later editing if needed

## Context Preservation

### Document Memory System
1. Maintain a running summary of each section as completed
2. Track key elements in the document:
   - For fiction: characters, settings, plot points, themes
   - For non-fiction: arguments, evidence, key terms, conclusions
3. Update these summaries after completing each section

### Section Handoff Protocol
When concluding a work session:
1. Save a "session state" note with:
   - Current section number and title
   - Key points just covered
   - Intended next steps for the following session
   - Any unresolved issues or questions

## Quality Assurance

### After Each Section
1. Check for consistency with earlier sections
2. Verify transitions flow naturally
3. Ensure stylistic elements remain consistent
4. Update the document memory system with new elements

### Document Review Process
1. When the document is complete, run a full continuity check
2. Review all transitions for smooth flow
3. Verify all characters/arguments remain consistent throughout
4. Check for unresolved elements or abandoned threads

## Implementation Notes
- This skill works with both creative and analytical writing
- Adapt the specific tracking elements based on document type
- Use the templates in the templates/ directory for consistent formatting
- Reference the documentation in docs/ for specific techniques
